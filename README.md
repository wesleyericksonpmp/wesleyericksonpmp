# Wesley Erickson

Business Transformation Consultant and PMP in Des Moines, Iowa. I improve how work gets done with the tools teams already have, automate the manual follow-up, and help people actually use what we build.

## What I build

- **Intake, governance and portfolio workflows** in Microsoft 365: SharePoint Lists, Power Automate and Power BI
- **Automation that removes manual work:** approvals, notifications, status updates and reporting that used to live in inboxes and spreadsheets
- **Copilot where it helps:** prompt libraries, standards and training so teams get value from the licenses they already pay for
- **Small tools that need no install or IT ticket:** single HTML files and lightweight Windows apps
